# 🤖 AI-MINI-PROJECTS

## 📌 Project Overview
This repository contains a collection of simple **AI and NLP mini projects** built using Python and Large Language Models.  
These projects demonstrate how AI can assist in tasks like answering questions, writing emails, correcting grammar, summarizing text, chatting in the terminal, and generating code.

The goal of this repository is to provide **beginner-friendly AI projects** for learning Natural Language Processing and building AI applications.

---

# 🚀 Projects Included

## 1️⃣ AI Terminal Chatbot

### Description
An AI chatbot that runs in the terminal and allows users to interact with an AI assistant through conversation.

### Features
- Interactive chat in terminal
- Continuous conversation loop
- AI-generated responses

### Example

Input
```text
Hello AI
```

Output
```text
Hello! How can I assist you today?
```

---

## 2️⃣ AI Code Generator

### Description
This tool generates programming code based on user prompts.

### Example

Input
```text
Create a Python function to calculate factorial
```

Output
```python
def factorial(n):
    if n == 0 or n == 1:
        return 1
    return n * factorial(n-1)
```

## 3️⃣ AI Question Answering System (AI Tutor)

### Description
The AI Tutor answers questions asked by the user using an AI language model.

### Example

Input
```text
What is Machine Learning?
```

Output
```text
Machine Learning is a branch of Artificial Intelligence that allows computers to learn from data without being explicitly programmed.
```

---

## 4️⃣ AI Email Writer

### Description
The AI Email Writer generates professional emails based on user input.

### Inputs
- Recipient
- Subject
- Purpose

### Example

Input
```text
Recipient: Manager
Subject: Leave Request
Purpose: Requesting leave for two days
```

Output
```text
Subject: Leave Request

Dear Manager,

I would like to request leave for two days due to personal reasons.
Kindly grant me permission for the same.

Best regards
```

## 5️⃣ AI Grammar Corrector

### Description
This tool automatically corrects grammar mistakes in sentences and supports multiple languages.

### Example

Input
```text
she go to market yesterday
```

Output
```text
She went to the market yesterday.
```

## 6️⃣ AI Text Summarizer

### Description
The AI Text Summarizer converts large text into a short summary while keeping the key information.

### Example

Input
```text
Artificial Intelligence is a branch of computer science focused on creating systems capable of performing tasks that normally require human intelligence.
```

Output
```text
Artificial Intelligence develops systems capable of performing tasks that require human intelligence.
```
